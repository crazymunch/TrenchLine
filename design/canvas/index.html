TrenchLine — interface artboards

Seven screens for a Trench Crusade warband builder. Every value shown is real: joined from a live NewRecruit roster export against the app's generated dataset. Colours, type, radii and control sizes are lifted from the running app's globals.css and components, not invented. Each frame below is one artboard; its source is the matching .dc.html file, plain HTML and CSS with no build step.
